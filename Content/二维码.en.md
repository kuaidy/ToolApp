## QR Code Generator

Enter text or a link to generate a QR code and download the image for sharing, menus, and promotions. This page uses the open-source **QRCodejs** component.

### How to use

1. Enter content or a full `https` URL
2. Generate and preview the QR code
3. Download the image for print or posters

### FAQ

**Can I generate a URL QR code?**  
Yes. Paste a full `https` link to create a scannable code that opens the page.

**What if the content is too long?**  
Long text makes denser modules that are harder to scan; shorten the link when possible.

### Dependencies

- [QRCodejs](https://github.com/davidshimjs/qrcodejs)
