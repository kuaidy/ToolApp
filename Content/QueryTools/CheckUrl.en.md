## URL Availability Check

Check whether a URL is reachable and inspect the response—useful for finding broken links. Some sites block probes or require login; treat results as indicative only.

### How to use

1. Paste the URL to check
2. Start the check
3. Review the response

### Related reference

After you see a status code, use the on-site [HTTP status codes](/tabletools/httpstatuscode) reference to interpret it.
