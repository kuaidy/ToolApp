## Bead Pattern Generator

Upload an image to generate a perler / fuse-bead pattern and color counts **locally in your browser**—no server upload. Adjust grid width and max colors, preview grid and bead holes, then download a PNG pattern.

### How to use

1. Select a local image (JPG / PNG / WebP, etc.)
2. Set grid width (presets like 29 / 40 / 50 / 58) and max colors
3. Generate the pattern and review the palette stats
4. Download the PNG pattern for crafting

### FAQ

**Are images uploaded to the server?**  
No. Reading, sampling, color reduction, and download all happen locally.

**How do I choose grid width?**  
Common boards are about 29, 40, 50, or 58 beads wide. Larger grids keep more detail but take longer to assemble.

**What should max colors be?**  
Use 0 for unlimited colors; 8–32 better matches common bead palettes for shopping. Transparent areas are skipped by default and do not count as beads.
