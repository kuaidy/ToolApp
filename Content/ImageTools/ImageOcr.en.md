## Image OCR (Text Recognition)

Extract editable text from screenshots, scans, or photos. Recognition on this site uses **Tesseract OCR**, suitable for office excerpts, receipt organization, and digitizing materials.

### How to use

1. Open this page and select the recognition language (e.g. Simplified Chinese + English)
2. Upload or select an image (common formats such as PNG, JPEG, TIFF; single file up to about 12 MB)
3. Wait for recognition to finish, then review the text in the result area
4. Copy the text as needed, or change the language and recognize again

### FAQ

**Which languages does this OCR tool support?**  
Multiple Tesseract language packs are built in. Simplified/traditional Chinese and English are commonly used; Japanese, Korean, and others are also available.

**Are images sent to third parties?**  
Recognition runs on this site’s server and is not forwarded to unknown third parties. Do not upload highly sensitive ID or credential images.

**What if recognition is inaccurate?**  
Use high-contrast, upright, clear images; crop irrelevant areas, or retry with a sharper screenshot.

### Tips

- Clearer source images with larger text usually yield better results
- Dark backgrounds, skewed text, or heavy blur are harder to recognize
- You can edit the result directly in the output box before copying
