## Image Compression

Compress JPG, PNG, WebP, and other images online, balancing file size and visual quality—ideal before uploading.

### How to use

1. Upload the original image
2. Choose quality or target-size options
3. Start compression and preview the result
4. Download the compressed file

### FAQ

**Does compression reduce quality?**  
Lossy formats trade some detail for smaller size; use the preview to pick a suitable quality.

**Which formats are supported?**  
Common JPG, PNG, WebP, and others as shown on the page.

**Is it good for social media uploads?**  
Yes. It helps bring oversized images within platform limits while keeping acceptable appearance.
