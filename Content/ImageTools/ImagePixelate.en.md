## Image Pixelate

Upload an image to create a mosaic / pixel-art effect **locally in your browser**—no server upload. Adjust block size, preview, then download a PNG (same dimensions as the original).

### How to use

1. Select a local image (JPG / PNG / WebP, etc.)
2. Set the block size (presets like 4 / 8 / 12 / 16)
3. Apply pixelation and preview
4. Download the PNG

### FAQ

**Are images uploaded to the server?**  
No. Reading, processing, and download all happen locally.

**How do I choose block size?**  
Larger values make coarser pixels with less detail; try 8–16 first.

**Does output size change?**  
No. Width and height stay the same; only the look becomes blocky.
