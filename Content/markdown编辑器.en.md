## Markdown Editor

Edit and preview Markdown online—ideal for docs, README files, and notes. This page uses the open-source **editormd** component and supports common extensions (e.g. math, diagrams, depending on editor capabilities).

### How to use

1. Write or paste Markdown in the editor
2. Check the rendered preview
3. Copy the Markdown source or export as needed

### Dependencies

- [editormd](https://github.com/pandao/editor.md)
- [Official site](https://pandao.github.io/editor.md/)
