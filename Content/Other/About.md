# 关于 ToolApp

[ToolApp](https://toolapp.org) 是一套在浏览器中使用的在线小工具集合，无需安装客户端。站点基于 **ASP.NET Core 9** 与 **Blazor Server** 构建，部分能力在服务端处理（如图片 OCR、压缩、高清放大），部分则在浏览器端完成（如手写签名、背景去除预览），兼顾实用性与隐私（图片默认在本地或当前会话中处理，不上传至第三方）。

工具按类别组织，主要包括：

- **图片工具**：文字识别、手写签名、背景去除、尺寸调整、压缩、高清放大等
- **文本工具**：字数统计、JSON 格式化、Markdown 编辑、正则测试、中英文排版等
- **转换工具**：进制转换、大小写切换、时间戳、GUID 等
- **对照表**：HTTP 状态码、Git 命令、MIME 类型、Linux 命令、Emoji 等速查
- **查询工具**：IP 查询、URL 检测等
- **效率工具**：番茄钟等

页面说明文档使用 Markdown 编写，由 [Markdig](https://github.com/xoofx/markdig) 渲染；工具页采用统一的 `tool-page` 样式，支持中英文界面切换。

### 2026-06-16

- **工具页布局统一**：文本、转换、编码、生成、查询、对照表、效率等页面采用 `it-hero` + `it-studio` 绿色工作区样式；增强 `Description` 组件，对照表与关于/捐助/小程序页同步套用
- **图片工具交互**：压缩、尺寸调整、高清放大、OCR、背景去除、图片合并等页面改为「上传后再显示操作区与预览」；合并页优化预览区布局与棋盘格背景
- **IP 归属地查询**：改用 `ipwho.is` JSON 接口；本地/内网访问时自动查询公网 IP；启用反向代理转发头支持

- **首页工具图标**：重绘图片尺寸、压缩、高清、合并、文章格式化、链接检测、ASCII 等 SVG 图标，风格与站点主色一致

- **全站 SEO / GEO**：按路径统一标题与描述、结构化数据（WebPage / FAQ / HowTo）、扩展 sitemap，并增加 `llms.txt`
